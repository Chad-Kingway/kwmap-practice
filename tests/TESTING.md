# 測試說明

目前有兩個測試檔案。

## 執行方式

在專案根目錄執行：

```sh
node --test tests/*.test.js
```

也可以只執行其中一個檔案：

```sh
node --test tests/proj01-route.test.js
node --test tests/proj01-flow.test.js
```

## 路線資料測試

檔案：[tests/proj01-route.test.js](proj01-route.test.js)

受測程式：[src/proj01/proj01-route.js](../src/proj01/proj01-route.js) 的 `parseCoordinate()`、`validateEndpoints()` 與 `normalizeDirections()`。

- 檢查起終點座標是否有效，且不能相同。
- 按順序接起路段，移除相鄰重複點，保留繞行路線。
- 拒絕接不起來、方向相反或經緯度顛倒的路段。
- 允許路段起點資料與解碼座標有小幅誤差。
- 拒絕沒有完整路段、座標無效或只有一個位置的路線。

## 查詢與播放流程測試

檔案：[tests/proj01-flow.test.js](proj01-flow.test.js)

受測程式：[src/proj01/proj01.js](../src/proj01/proj01.js)，搭配路線驗證與整理函式。

使用模擬的畫面控制項與 SDK，檢查以下流程：

- 沒有有效路線時，不能開始播放。
- 查詢中不重複送出；逾時後可重試。
- 新查詢成功後，舊回應不會改寫新路線狀態，也不會自動播放。
- 查無路線時，保留上一條有效路線。
- 換路線後，清除舊線與標記。
- 播放使用新路線，期間不能查詢，結束後恢復操作。
- 路徑移動區的秒數及開始按鈕在播放中停用，但跟隨按鈕仍依跟隨狀態可操作，解除跟隨使用地圖左鍵拖曳。
- 車輛區共用 fieldset 只在尚未就緒時停用；查詢及播放期間分別停用輸入，保留路線顯示及跟隨操作。
- 查詢與播放期間，路線顯示仍可切換，不受起終點查詢停用影響。
- 路線切換後重繪最終物件狀態，關閉立即清除、重新勾選立即呈現；人工確認時保持地圖不動，連續切換數次。
- 車子使用道路吸附後的起點，模型、路線、起終點標記與重播路徑皆使用地面基準高度 0；沒有高度輸入。規劃完成就對準第一路段。
- 重播的起點及朝向一致，播放固定使用 SDK 自動朝向。
- 查詢失敗或幾何無效時，車子的位置與朝向不變。
- 沒有手動角度與自動朝向選項，播放時不呼叫手動旋轉。
- 地圖左鍵位移達 5px 解除跟隨；點擊、小移動、右中鍵及另一指標不誤觸。
- 放開、取消、移出地圖與視窗失焦後不殘留手勢。
- 待鎖定及過期回呼不會在拖曳解除後重新鎖回；解除、重播都不重啟或停止播放。
- 選點可切換起終點、再次按同一按鈕或 Escape 取消；只填入有效左鍵點擊座標，保留精度。
- 拖曳、右中鍵、面板來源、取消手勢及無效座標不誤選；連續選點不自動規劃或改變既有路線、標記與模型。
- 選點取消已鎖定與待鎖定跟隨；查詢或播放會取消選點，期間不能重新選取。

此測試不會連線到真實服務，也不檢查地圖與模型的實際顯示效果。

車輛區人工測試：確認「車輛 01」預設展開，滑鼠、Enter 與 Space 可收合／展開；收合後沒有內容空白，重新展開保留輸入。查詢與播放途中收合應繼續運作，跟隨狀態保持，展開後仍可切換路線及使用原有跟隨操作。窄螢幕確認上方面板自然縮短，面板滾輪仍不影響地圖。

地圖選點人工測試：開啟 `/?example=proj01`，切換起終點模式，測試再次按下與 Escape 取消，再左鍵點圖確認座標填入。拖曳、右中鍵與面板操作應保留模式；跟隨中選點應解除跟隨。選點後另按規劃並播放，確認舊路線只在查詢成功後替換。已實測桌面、390px 與 350px 窄螢幕的連續選點、取消、拖曳排除、成功規劃、播放與跟隨；待鎖定回呼的取消由模擬測試驗證。

已移除將模型初始校正硬編碼為 Y=0 的檢查；目前素材正確校正為 `{ x: 90, y: 180, z: 0 }`，姿態以實際畫面確認。同一流程測試中的道路吸附起點、方向、重播及失敗保留狀態檢查仍保留。人工檢查請先觀察模型初始姿態，再規劃路線確認起始朝向，最後播放含轉彎的路線觀察轉向。

本次人工檢查另觀察到播放起步時約 180 度的朝向切換；模型保持正立並隨路線轉向，但起始朝向與 SDK 自動朝向仍有落差。本次未修改方向功能，自動測試通過不代表此畫面問題已修正。

精簡介面測試：合併座標接受逗號前後空白，空值、缺值、多值、非數值及超出範圍不會送出查詢；地圖選點保留精度並寫入同一欄位。比例僅按「套用」才更新，無效比例不套用且不改位置或旋轉；動畫秒數驗證與毫秒轉換保持不變。人工確認輸入、右側選取／套用按鈕與秒數單位在桌面和窄螢幕對齊，收合再展開保留輸入。

本次已實測桌面及 320px 窄螢幕：空座標錯誤提示、含空白座標成功規劃、地圖選點填入合併欄位、套用比例、收合保留輸入、兩秒播放與跟隨／拖曳解除，並確認沒有水平溢出。

需求管理測試：查詢及播放中仍可選取，依唯一 id 保留單選與重繪狀態；重複選取、無效 id 不誤改狀態，且不改起終點輸入、路線、標記、車輛動畫或鏡頭。清理後移除需求監聽器。人工確認預設未選、滑鼠及鍵盤單選、車輛收合不隱藏需求，並在窄螢幕與跟隨中測試面板捲動。

需求圖層測試：依序查詢一次並快取驗證後的道路幾何，選取不重查；載入後使用當下選取的線寬及端點外框。逾時、無路線、遲到回應與釋放不影響其他需求；車輛路線切換保留需求圖層，選取不改車輛、輸入或鏡頭。

人工複驗：縮小／平移地圖查看三組不同顏色端點與道路線，切換 radio 確認立即加框、加粗；再手動規劃、切換車輛路線顯示並播放／跟隨。確認需求圖層保留，面板捲動與窄螢幕正常。實際服務三筆均成功；失敗隔離及不重查的計數由模擬測試驗證。

指定接送測試：立即保留需求，切換選取與連點不能更換任務；從模型當下位置查接人道路，送人沿用快取，以有效 onEnd 順序接續並按道路長度分配總時間。近起點略過接人，完成停在終點且不能重接；任務不覆蓋手動路線或需求圖層。查詢逾時、道路銜接不合理、舊回應、重複回呼與釋放不啟動新動畫；動畫拒絕保留乘車狀態，等待結束才解除忙碌。

人工複驗：選取需求並接送，確認接人、送人、終點停車及下一筆接送；執行中切換 radio、連點與拖曳解除跟隨，車子仍服務原需求。再手動規劃、切換路線及播放，需求預覽應保持。查詢逾時與 SDK 動畫拒絕由模擬測試驗證；未確認可用的公開停止方法，若動畫異常且不回報 onEnd，需重新整理。
