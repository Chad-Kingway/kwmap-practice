# 測試說明

執行：`node --test tests/*.test.js`；建置：`npm run build`。

- `proj01-route.test.js`：座標及完整道路幾何、路段順序與連接誤差、官方 leg 秒數加總；缺失時間保留道路但禁止接送。
- `proj01-playback.test.js`：可控制 RAF 時間及可見性，驗證固定與動態倍率、位置連續、不同點密度、重複點、跨點轉彎與方向、同幀路段餘量、完成一次、取消／過期更新／清理、位置或鏡頭錯誤及背景恢復。鏡頭更新保留使用者縮放與俯角。
- `proj01-flow.test.js`：模擬 DOM 與 SDK，搭配正式自管控制器，驗證需求新增／選點／快取／預覽、指定與自動單筆接送、準備失敗及逾時、接人送人銜接、最新倍率及需求只完成一次、錯誤保留乘客狀態、定位跟隨互斥與拖曳解除、比例忙碌限制及 POI 顯示。舊 followPath 回呼測試已改為時間推進或 setter 故障。

## 人工複驗

開啟 `/?example=proj01`，選需求 02，開啟跟隨並接送。準備及移動中連續拖動 1～300 倍率，確認倍率即時顯示、車位不回起點、朝向跟著道路轉彎、鏡頭持續跟隨；比例及選點仍停用。拖曳地圖解除跟隨後可定位，再啟動跟隨。切到背景一段時間再回來應接續當下進度。完成後需求顯示已完成、車停終點、比例恢復，且不自動下一筆。

本次真實 mapThree 1.4.3 已完成需求 02 的接人及送人，測過播放中加減速、連續滑桿拖動、拖曳解除／定位／重新跟隨。隔離固定折線實測向東及向北朝向、東→北→西轉彎、單次開始／完成、終點讀回誤差 0、空 SDK 路徑佇列及取消後再播放。診斷頁為 `/.local-debug/stage2.html`，檔案被 Git 忽略；不另外載入 SDK、Three.js 或 MapLibre，不查路線服務。

背景恢復、精確時間積分、跨段餘量、取消的過期幀及注入錯誤由模擬測試確認；未以 mock 宣稱這些瀏覽器情境已實測。多車僅既有比例登記有模擬測試，未實作多車移動。
