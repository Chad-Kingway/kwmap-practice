# 測試說明

執行：`node --test tests/*.test.js`；建置：`npm run build`。

## proj01-route.test.js

測試座標解析、有效範圍與不同起終點；完整道路幾何按 leg／step 順序連接，只去除相鄰重複點。拒絕反向、斷裂、缺失、無效座標，容許官方 polyline 小數五位量化誤差。只加總有效 `leg.duration.value` 秒數，不重複加入 route／step；缺失、非數值與溢位時間仍保留道路。

## proj01-flow.test.js

以模擬 DOM 與 SDK 驗證重要流程，不連線真實服務：

- 草稿驗證、地圖選點與取消，拖曳／非左鍵／面板／失焦不誤選；不移動車輛或自動建立需求。
- 新增固定 id 與座標副本，只附加一次；保留選取、接送狀態及每筆 checkbox，接送中仍可新增。
- 初始化及閒置佇列新增都依序查一次；ready 快取、獨立失敗、逾時、舊回應及釋放。
- 每筆預覽隱藏／顯示立即生效，不重查、不改選取與任務線；查詢完成、狀態更新與清單重呈現保留顯示狀態。
- 指定／自動接送同步保留任務，從當下車位接人，送人沿快取；各段用官方秒數轉毫秒並除以開始時保存的共用倍率，以有效 onEnd 接續。近起點只播放送人時間；線性滑桿直接使用整數倍率，涵蓋 1×／300×、預設 60×、中段及忙碌時輸入不改倍率。
- 自動接送只比較原始起點距離、同距離按清單順序；完成不連續接送，再操作使用最新位置，排除非 pending／非 ready。
- 連點及切換選取不換任務；準備失敗回 pending 且位置不變，動畫拒絕保留上車狀態，等待結束才解鎖，重複／舊回呼失效。
- 保留 z=0、比例及倍率驗證、SDK 自動朝向、鏡頭跟隨與拖曳解除；解除跟隨不停止動畫。送人時間無效仍保留道路預覽且禁止接送；接人時間無效回 pending、不移動，舊回應不能重新啟動。
- 定位讀取模型當下座標，只更新鏡頭中心，不移動模型或中斷接送；拒絕無效座標，跟隨及待鎖定時禁止定位，解除後恢復。
- POI 切換立即重繪，僅影響 `poi_` 圖層；路名、需求、車位與接送保留。樣式重載沿用選擇，來源載入不誤停用；失敗還原狀態，釋放後舊事件無效。
- 全域比例套用後立即重繪，相同值不累乘；新模型繼承成功值、任一模型忙碌時禁止修改。無效值或部分套用失敗不更新全域成功值，清理後不能操作。多模型僅模擬測試，未實測。

已移除僅適用於車輛手動路線查詢、安裝及重播的測試；共用選點、需求道路驗證、接送、鏡頭與失敗隔離仍測試。素材校正保留 `{ x: 90, y: 180, z: 0 }`，不以 Y=0 的斷言取代畫面確認。

## 人工複驗

開啟 `/?example=proj01`，用輸入及選點新增需求，確認車位不變、草稿清空、端點與道路出現。逐筆切換 checkbox，測試查詢中取消、重新勾選、radio／鍵盤及新增保留狀態。接送中新增並隱藏預覽，任務線與服務對象不變；新需求 ready 後可接送。測桌面、窄螢幕、車輛收合與跟隨中面板捲動。

實際播放的終點座標未到達及起步朝向落差仍待排查；未確認可用的公開停止方法，異常且不回報 onEnd 時需重新整理。模擬通過不代表這些 SDK 畫面問題已解決。

比例人工複驗：收合車輛後仍能操作模型設定，依序套用 20、20、5，確認立即呈現且不累乘；測空值與超出範圍、跟隨中套用、接送期間停用與完成後恢復。

已實測單車即時放大／縮小、重複套用、無效值拒絕、車輛收合、跟隨中套用及接送完成後恢復，350px 排版無水平溢出。多模型繼承、任一模型忙碌與部分失敗以模擬測試驗證，尚未實測多車；一次接送完成不代表既有 SDK 終點與朝向問題已修正。

定位人工複驗：靜止與接送中按「定位」，收合後也能操作；定位按鈕以滑鼠、Enter、Space 啟動均不切換展開狀態，標題其他位置及鍵盤仍可展開／收合。已實測上述操作、跟隨時停用、拖曳解除後恢復及 350px 無溢出；無效座標與待鎖定事件攔阻以模擬測試驗證，zoom／pitch／bearing 數值保持由模擬測試確認。

POI 人工複驗：操作地圖右上角圖示，連續隱藏／顯示，確認圖標與地點名稱立即更新，路名、需求線與車輛保留；接送及鏡頭跟隨中也可操作，圖示、title、aria-label 與 aria-pressed 對應狀態。已實測滑鼠、Enter／Space、焦點樣式、選點期間不誤填座標、按鈕拖曳不解除跟隨、正常地圖拖曳解除跟隨及 350px 無溢出；SVG 經多次同步仍保留。樣式重載、切換失敗及監聽釋放以模擬測試驗證，未在瀏覽器實際重載樣式或注入 SDK 失敗。

配速人工複驗：用滑桿設定倍率，Home／End 應顯示 1×／300×，方向鍵即時更新整數值及 aria-valuetext，預設 60×。準備與播放中滑桿停用，任務結束恢復；在 60× 下接人 300 秒、送人 600 秒分別約 5 秒、10 秒，近起點只播放送人。瀏覽器已確認 Home／End、方向鍵、滑桿點擊、整數顯示與 aria-valuetext，不取消跟隨；準備／播放停用，單段完成後恢復，350px 無水平溢出。實際回傳 `leg.duration.value` 數值 254、369、459。10× 近起點單段送人正常完成，車輛停在終點，跟隨期間 POI 可切換；60× 仍重現既有 SDK 終點檢查中斷。完整兩段到站、缺失時間、倍率快照與精確播放時長由模擬測試驗證，尚未完整實測。

本次線性滑桿尚未重新進行瀏覽器複驗。
