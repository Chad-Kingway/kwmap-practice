# 測試說明

執行：`node --test tests/*.test.js`；建置：`npm run build`。

- `proj01-route.test.js`：座標及完整道路幾何、路段順序與連接誤差、官方 leg 秒數加總；缺失時間保留道路但禁止接送。
- `proj01-random-request.test.js`：可控制亂數，驗證矩形抽樣與經緯度順序、公尺距離不足時重抽、嘗試上限。
- `proj01-playback.test.js`：可控制 RAF 時間及可見性，驗證固定與動態倍率、位置連續、不同點密度、重複點、跨點轉彎與方向、同幀路段餘量、完成一次、取消／過期更新／清理、位置或鏡頭錯誤及背景恢復。鏡頭更新保留使用者縮放與俯角。
- `proj01-flow.test.js`：模擬 DOM 與 SDK，搭配正式自管控制器，驗證需求新增／選點／快取／預覽、指定與自動單筆接送、準備失敗及逾時、接人送人銜接、最新倍率及需求只完成一次、錯誤保留乘客狀態、標題列跟隨與拖曳解除、比例忙碌限制及 POI 顯示。舊 followPath 回呼測試已改為時間推進或 setter 故障。

## 人工複驗

座標草稿流程測試涵蓋展開／收合保留原文、編輯取消選點、輸入中不驗證、收合焦點移回、地圖選點同步摘要、成功新增清空，以及接送跟隨中切換與隨機新增保留草稿及展開狀態。瀏覽器複驗另確認隱藏輸入不能 Tab 聚焦、摘要安全顯示及窄螢幕排版。

本次真實 SDK 已確認上述 Tab 順序、安全摘要、收合選點與新增清空；需求 01 接送跟隨中編輯、收合及隨機新增仍保留草稿與原任務。280px 三鈕同列、240px 自動換行，面板均未水平溢出。

隨機需求的流程測試涵蓋單次新增、草稿與選取保留、抽樣失敗不新增、沿用查詢佇列與路線／時間資格、接送及跟隨中新增不改任務。瀏覽器複驗：填草稿並選需求，按「隨機需求」確認一筆新增、端點與道路線出現；接送及跟隨中再按一次，確認草稿、選取及原任務持續。

本次真實 SDK 複驗：閒置與需求 02 接送／跟隨中各新增一筆（需求 04、05），端點立即顯示且官方道路查詢完成，兩筆草稿與原選取保留，原任務持續前往接人；桌面及 360px 面板均未水平溢出。抽樣上限、路線／時間失敗及禁止接送由可控制亂數的模擬測試驗證。

開啟 `/?example=proj01`，選需求 02，開啟跟隨並接送。準備及移動中連續拖動 1～300 倍率，確認倍率即時顯示、車位不回起點、朝向跟著道路轉彎、鏡頭持續跟隨；比例及選點仍停用。拖曳地圖解除跟隨後，可從標題列再次啟動跟隨。切到背景一段時間再回來應接續當下進度。完成後需求顯示已完成、車停終點、比例恢復，且不自動下一筆。
