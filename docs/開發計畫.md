# 目前狀態

已完成第一階段 SDK 驗證與第二階段單車途中改速，採方案 C 自管模擬時間、道路位置及朝向。mapThree 1.4.3 的 followPath 沒有已確認可靠的公開途中改速介面，fixedCameraToModel 依賴路徑動畫佇列，且 SDK onEnd 曾早於實際到站，因此正式接送不再依賴它們。

單車共用時間控制已集中：RAF 累積實際秒數乘當下 1～300 整數倍率，各段使用官方 durationSeconds，依道路累積距離插值；接人送人交接餘量。公開 setCoordinates／setRotation 更新模型，jumpTo／redraw 同幀維持跟隨，保留素材初始校正。背景暫停、恢復基準、取消與過期識別已處理。

可控制時間的測試涵蓋改速、幾何、跨段及清理；真實 SDK 已完成兩段接送、朝向、轉彎及途中改速跟隨。背景恢復與注入錯誤尚屬模擬測試結果；目前沒有第二台車、派車演算法或後端。

# 第三階段：擴充全車共用時間控制

1. 在現有模擬時鐘加入少量車輛登記與移除，共用同一倍率及更新迴圈。
2. 每車保存獨立播放識別、路線進度及接送狀態，沿用開始／完成／錯誤介面。
3. 驗證不同時間出發、同步改速、各自到站與取消，避免車輛互相覆蓋。
4. 指定鏡頭跟隨對象，保留拖曳解除及定位互斥。
5. 複驗多車背景暫停、恢復與資源清理，再決定後續派車規劃。
