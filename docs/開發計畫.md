目前已完成需求管理、地圖呈現、指定與最近需求接送，以及新增需求和每筆路線顯示。

## 目前狀態
- 需求管理位於車輛區外，保留三筆預製資料；起終點草稿可手動輸入或地圖選點，驗證後建立固定唯一 id、起終點副本、穩定色盤、pending 與預設顯示狀態。資料僅在記憶體。
- 新增局部附加清單與端點，保留 radio 選取、焦點與各筆顯示狀態。送人道路透過同一佇列依序查詢一次、驗證並快取，失敗保留需求與標記。
- 每筆「路線」只控制自己的送人預覽，取消不清快取、不影響接送資格；重新勾選立即重繪，選取／狀態更新不重開隱藏線。
- 模型比例位於獨立全域設定，以模型建立比例換算並立即重繪；草稿與成功值分開，後續登記模型繼承成功值，任一模型忙碌時禁止套用。部分失敗不宣稱全部成功，目前僅一台實際車輛。
- 車輛區保留接送總展示秒數、指定／自動接送與鏡頭跟隨；已移除手動路線。接送期間仍可手動填草稿及新增需求，選點暫停，不改當前車位、任務或鏡頭。
- 指定接送使用選取 id；自動接送從模型當下位置比較原始起點直線距離，候選須 pending 且路線 ready，同距離按清單順序。每次僅執行一筆，不自動接下一筆或在失敗後換單。
- 任務以當下車位查接人道路、沿快取送人道路；5 公尺內可略過接人，實際道路端點吸附／銜接容許 50 公尺，不補直線。按路長分配總展示時間，onEnd 接續，完成清除獨立任務線並停在道路終點。
- 接送狀態為 pending → assigned → pickingUp → onboard → completed，與路線載入分開；準備失敗回 pending，動畫後失敗保留乘客狀態並等待有效結束回呼。
